## 第三方组件与分享限制

应用源码采用 MIT License；这不覆盖应用包中的 Qt/PySide6、FFmpeg/ffprobe 等第三方组件。

Windows 候选包随附 FFmpeg 9.0.1 Gyan “full” 静态 GPLv3-or-later 构建，包含 `libx264`。Mac 候选包实际使用 Homebrew FFmpeg 9.0.1_1 GPL-3.0-or-later，启用 `libx264`/`libx265`，并随包复制其动态库依赖；此前包内的 `FFMPEG_BUILD_INFO.txt` 保存了 Homebrew 公式元数据和版本清单。[Gyan 构建说明](https://www.gyan.dev/ffmpeg/builds/)声明其 Windows 静态构建为 GPLv3；[FFmpeg 官方许可说明](https://ffmpeg.org/legal.html)也指出启用 GPL 部件会使 FFmpeg 本体适用 GPL。两平台这两个精确构建及全部外部库的对应源码、构建输入与再分发材料尚未逐项收集核验。

另对两个归档都做了实际文件清点：Windows 包含 QtCore、QtGui、QtMultimedia、QtMultimediaWidgets、QtNetwork、QtWidgets 的 Python 扩展，以及多个 Qt 运行库/插件；Qt Multimedia 后端有 `ffmpegmediaplugin.dll` 和 `avcodec-61.dll` 等 FFmpeg DLL。macOS 包包含 QtCore、QtDBus、QtGui、QtMultimedia、QtMultimediaWidgets、QtNetwork、QtWidgets 扩展；Qt Multimedia 插件目录有 `libffmpegmediaplugin.dylib`，并带有 Qt 自己的 `libavcodec.61.dylib`、`libavformat.61.dylib`、`libavutil.59.dylib`、`libswresample.5.dylib`、`libswscale.8.dylib`。这些 FFmpeg 库与应用额外打包的 FFmpeg/ffprobe 及其依赖是两套独立二进制，仍需分别核对精确版本、许可证、第三方告知、对应源码和可替换性。当前 PySide wheel 元数据声明 LGPL/GPL 多重许可，但这本身不等于发行包已满足再分发要求。参考 [Qt for Python 许可清单](https://doc.qt.io/qtforpython-6/licenses.html)、[Qt 许可说明](https://doc.qt.io/qt-6/licensing.html)和 [Qt 6.11.2 官方源代码归档](https://download.qt.io/archive/qt/6.11/6.11.2/single/)；通用 Qt 源码归档本身不能证明覆盖了所有随包二进制及其第三方代码。

## 首次启动和反馈

- Windows：解压后从文件夹运行“映序.exe”，不要只复制 exe；FFmpeg、ffprobe 和运行库必须与程序文件放在一起。若 Windows 安全提示无法确认发布者，请先核验来源及 SHA-256；不确定时不要继续运行。
- macOS：候选包未签名、未公证，首次打开可能被 Gatekeeper 拦截。仅在确认文件来自本项目且校验值匹配后，按系统“隐私与安全性”中的提示允许打开；不要关闭整机安全保护。仅支持 Apple Silicon（arm64）的候选包，Intel Mac 不适用。
- 欢迎反馈问题。请附系统版本、设备/芯片型号、复现步骤和已脱敏的错误信息；不要上传私人视频、API 密钥或含个人路径的日志。

日常剪辑默认在本机处理媒体；只有用户主动确认 API 分析时，才会向所选服务商发送任务文本、素材文件名和时间戳台词，不发送视频文件或本机绝对路径。服务商可能收费。

## API 分析与费用估算

- DeepSeek 官方接口的模型快捷项为 `deepseek-flash` 和 `deepseek-v4-pro`；也可手动输入其他兼容服务商的 API 地址与模型 ID。其他服务商的费率及模型输出限制不同，须以其官方文档为准。
- DeepSeek 官方 API 允许的最大 `max_tokens` 为 384K，模型上下文总量为 1M。应用对官方 DeepSeek 请求设置 `max_tokens=393216` 并关闭默认思考模式，避免非思考模式默认 8K 输出限制；384K 是允许的最大值，不是固定生成量或固定费用。对其他 OpenAI Chat Completions 兼容接口，应用不发送 `max_tokens`，由服务商自己的默认策略决定；其默认值也可能导致截断。
- 发送确认框显示 DeepSeek 高峰/低谷估算，尽量使用本机同模型的历史用量；无历史时按文字量粗估输入，并以旧请求输出量作参考。输入缓存按未命中估算，输出取历史值外推，因此不是报价。还会按历史用量/视频数线性外推“10个视频+10条切片”；固定提示词开销、字幕密度及截断都会令估值偏离，输出样本若曾以 `length` 截断会提示估值可能偏低。费用最终以服务商返回 usage 与账单为准。
- 截至 2026-10-07，DeepSeek Flash 每百万 tokens：低谷输入（未命中缓存）¥1、输出 ¥4；高峰输入 ¥2、输出 ¥8。低谷含工作日高峰时段以外、周末及法定节假日；高峰为北京时间周一至周五（不含法定节假日）9:00–12:00、14:00–18:00。官方说明 `deepseek-v4-pro` 当前请求路由至 V4.1-Flash，并按 Flash 价格计费，直到 V4.1-Pro 上线。价格和路由会变化，请发送前查看 [DeepSeek 官方模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。
- 同一批素材台词会整体进入每次请求；选择少做几条主要减少模型输出，不会明显减少输入。分成多次 API 请求会重复发送上下文，并分别计费。
