## 免费构建与临时下载

仓库为公开仓库，Mac 使用 GitHub 标准 macOS runner。GitHub 当前说明公开仓库的标准托管 runner 免费；GitHub Free 的 Actions 工件存储额度为 500 MB。工作流只保留 1 天，并限制单个候选包不超过 450 MiB，不使用付费 runner、付费订阅、签名证书或公证服务。临时工件需登录 GitHub 并具有仓库读取权限下载；过期后不会保留为长期下载链接。

## 第三方组件与分享限制

应用源码采用 MIT License；这不覆盖应用包中的 Qt/PySide6、FFmpeg/ffprobe 等第三方组件。

Windows 候选包随附的 FFmpeg 是 GPLv3-or-later 静态构建（包含 GPL 编码器），Mac 候选包从 Homebrew 获取 FFmpeg。每个候选包都记录构建信息，但对应源码与完整再分发材料尚未完成逐项核验。因此它们当前只用于内部试用和反馈，核验完成前不要公开转发或上传到共享下载区。此说明不是法律意见。

## 首次启动和反馈

- Windows：解压后从文件夹运行“映序.exe”，不要只复制 exe；FFmpeg、ffprobe 和运行库必须与程序文件放在一起。若 Windows 安全提示无法确认发布者，请先核验来源及 SHA-256；不确定时不要继续运行。
- macOS：候选包未签名、未公证，首次打开可能被 Gatekeeper 拦截。仅在确认文件来自本项目且校验值匹配后，按系统“隐私与安全性”中的提示允许打开；不要关闭整机安全保护。仅支持 Apple Silicon（arm64）的候选包，Intel Mac 不适用。
- 欢迎反馈问题。请附系统版本、设备/芯片型号、复现步骤和已脱敏的错误信息；不要上传私人视频、API 密钥或含个人路径的日志。

日常剪辑默认在本机处理媒体；只有用户主动确认 API 分析时，才会向所选服务商发送任务文本和素材目录信息，服务商可能收费。
